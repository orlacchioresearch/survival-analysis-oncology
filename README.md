# Survival Analysis in Oncology

This repository demonstrates a simple survival-analysis workflow using synthetic oncology data.

## What this repository includes

- Kaplan-Meier survival curves
- Cox proportional-hazards model
- Synthetic biomarker-positive and biomarker-negative cohorts
- Reproducible analysis script

## How to run

```bash
pip install -r requirements.txt
python src/survival_analysis.py
```

## Scientific interpretation

This example shows how a biomarker-defined group may be associated with different survival outcomes. The dataset is synthetic and should not be interpreted as evidence for any real biomarker.
